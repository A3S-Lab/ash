# ASON

ASON 是 ash 原生设计并实现的 LLM 优先结构化格式。它优先减少模型上下文中的重复
结构，同时保持严格 Schema、规范编码、流式边界和可恢复证据。

## 示例

```ason
s:0
a:search
d{p}:
0:"src/runtime.rs"
r{p,l,c}:
0,42,governor
0,88,stable_merge
z{shown,total}:
2,17
q:ref-7
```

- `s:0`：标量字段。
- `d{p}`：路径字典列。
- `r{p,l,c}`：同构搜索记录，列名只出现一次。
- `z{shown,total}`：投影元数据。
- `q`：完整证据引用，可以继续 slice 或 search。

## 规范规则

1. 字段和列顺序由消息 Schema 固定。
2. 安全文本使用裸 Atom；需要时使用 UTF-8 字符串与最短转义。
3. 重复字段、重复列、未知必需结构和非规范数字被拒绝。
4. 解析器在构造完整模型前执行文档、集合、字符串与深度限制。
5. decode 后再 encode 必须得到唯一字节序列。

## Token 证据

固定格式语料在 `cl100k_base` 与 `o200k_base` 两个锁定 tokenizer 上得到同一结果：

| 格式          | cl100k |  o200k | 相对紧凑行式 JSON |
| ------------- | -----: | -----: | ----------------: |
| 规范 ASON     |  6,313 |  6,312 |               62% |
| 紧凑行式 JSON | 10,192 | 10,198 |              100% |

这是格式语料回归数据，不是完整 Agent 任务质量或运行时性能结论。复现方式见
[基准证据](/guide/benchmarks)。

## 为什么不是普通 JSON

JSON 对每条同构记录重复键名，并倾向内联长路径和大值。ASON 将结构重复移到 Schema
与列头，把大值留在有界存储中，只给模型返回引用和必要投影。它不是另一个格式的兼容层。
