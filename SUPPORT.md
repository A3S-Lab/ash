# Support

`ash` is a pre-release implementation with no published supported executable
release. Source builds and repository test fixtures are available for
development, but installation and runtime support are not offered yet.

## Where to ask

- Use the question form for focused design questions.
- Use a feature or architecture issue for proposals.
- Use the bug form only for behavior that can be reproduced from repository
  content or a published artifact.
- Use [`SECURITY.md`](./SECURITY.md) for suspected vulnerabilities; never put
  sensitive details in a public issue.

Before opening an issue, search existing issues and read the relevant design
document. Include the affected commit, operating system, architecture, expected
contract, and minimal evidence when applicable.

This is a community open source project. Opening an issue does not create a
service-level agreement or guarantee a delivery date.
